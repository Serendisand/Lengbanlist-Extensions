# tp — 传送到玩家身边

```
/lban tp <玩家名>
```

| 项 | 值 |
| --- | --- |
| 扩展名 / 功能键 | `tp` |
| 命令 | `/lban tp <玩家名>`（`/lban` 的子命令） |
| 权限 | `lengbanlist.admin` |
| 补全 | 在线玩家名前缀 |
| 开关 | `extensions/tp/config.yml` 的 `enabled` |

控制台执行会得到"玩家不在线"——控制台没有身体，没法被传送。目标玩家离线时同样是这条提示。

这是第一个从核心搬出来的功能，选它的原因是它同时验证了两件事：Lua 注册的命令能无缝并进
现有的 `/lban` 命令树，以及**搬迁不改变用户看到的任何东西**（命令名、权限、用法提示、
补全行为都与内置版本一致）。
